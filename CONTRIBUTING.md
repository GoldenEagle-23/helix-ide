# Contributing to Helix

Thank you for considering contributing to Helix! We welcome issues, feature requests and pull requests.

## Development environment

1. Install Python 3.9 or newer.
2. Clone the repository.
3. (Optional) Create a virtual environment and install dependencies.

## Submitting changes

1. Fork this repository and create a new branch for your changes.
2. Follow the coding guidelines described in the documentation.
3. Submit a pull request with a clear description of your changes.

## Code of conduct

All contributors are expected to follow the Code of Conduct included in this repository.
