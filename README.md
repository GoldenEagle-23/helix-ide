# helix-ide
Helix Coding Agent V1.0 - AI-native development operating system. Includes version history from pre-alpha to v0.4, integrated AI model marketplace (OpenRouter, LangChain, HuggingFace, vLLM), GitHub MCP, filesystem MCP, CI watchers, CLI, VS Code extension. Hybrid cloud (Cloudflare, AWS, Google, Nebula). Open-core under Apache license.
