# Licensing

Helix is licensed under a dual-license model.

## Open Core (Apache 2.0)
The core agent runtime, CLI, filesystem MCP, and related components are available under the Apache 2.0 license. This allows free use, modification, and distribution.

## Commercial Modules
Some modules, such as the hosted AI gateway, team dashboards, live GitHub PR agents, and enterprise features, require a commercial Nebula license. These modules are not covered by the Apache license and must be obtained through Nebula for production use.

## Contributions
Contributions to the open-core components should follow the guidelines in `CONTRIBUTING.md`. By submitting a pull request, you agree to license your contributions under the same license as the file you are modifying.
