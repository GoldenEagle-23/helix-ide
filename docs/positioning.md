# Helix Coding Agent Positioning

Helix is an AI-native development operating system that abstracts over editors, models and cloud providers. It provides a unified interface for planning, implementing, testing and committing code changes.

Key differentiators:

- **Model Fabric**: dynamic routing across local and remote models (Ollama, vLLM, OpenAI, Claude, Grok, OpenRouter, HuggingFace, etc.).
- **MCP Architecture**: modular components for interacting with repositories, filesystems, CI services and deployment platforms.
- **IDE Agnostic**: works with VS Code, Neovim, Helix editor fork and more via extensions.
- **Open Core**: the core components are licensed under Apache 2.0; premium SaaS features are offered separately.
